Manlyeah Publisher

A personal content tool for the @manlyeah accounts

Manlyeah Publisher is a private tool operated by Manly (@manlyeah), an Indonesian technology creator who shares tips and solutions for PC and laptop problems. The tool is used only to manage the operator's own social media accounts. It is not offered to the public, and no other person can sign in to it.

What the tool does

  • Publishes the operator's own original posts (image carousels, photos and videos) to the @manlyeah accounts on Instagram, Threads and TikTok, using each platform's official API.
  • Schedules those posts at fixed daily times.
  • Reads performance data (views, likes, comments, shares, saves, reach) for the operator's own posts, to learn which topics help the audience most.
  • Finds trending topics by searching public Threads posts by keyword and looking at aggregate engagement. The tool never republishes other people's content. It only uses topic trends to decide what original content to create.
  • Sends notifications to the operator (for example, a draft waiting for approval). Every post is reviewed and approved by the operator before it is published.

Platforms used

  • Instagram API with Instagram Login (content publishing and insights)
  • Threads API (publishing, insights and keyword search)
  • TikTok Login Kit and Content Posting API
